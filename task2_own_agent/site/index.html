The team’s shared view

The Future of Software Engineering

AI is already a useful collaborator: it can help explore unfamiliar code, sketch alternatives, and turn a blank page into a first draft. It is not a substitute for understanding the problem, checking the result, or being accountable when production has feelings about Friday afternoon.

Today: faster starts, same responsibility

We expect AI tools to speed up routine work, but generated code still needs tests, context, and a human who can explain why it belongs in the project. “The model said so” is not a test case.

In 5–10 years: engineers orchestrate, verify, and design

We think engineers will spend more time expressing intent, connecting systems, reviewing agent work, and making careful trade-offs. The craft will shift—not vanish—and debugging will probably outlive every prediction that debugging is over.

Our forecast: more capable tools, more important judgment, and at least one mysterious flaky test.
