## What I think about AI in software engineering today
It's genuinely useful for exploring unfamiliar codebases and APIs quickly, but testing and validation still can't be skipped — an agent that looks confident and an agent that's correct are not the same thing.

## Where software engineering will be in 5–10 years
A lot of routine implementation work gets automated, so the actual engineering skill shifts toward architecture, security, and knowing which parts of a system you can't afford to get wrong.

## My hot take on AI
The agent that writes your code should scare you a little — if it doesn't, you're not reading its output closely enough.
